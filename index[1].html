Not connected
Training only. All incidents and patients are fictional. This MVP synchronizes classroom scenarios through Supabase and provides rule-based demo patient replies plus browser speech. It is not a real dispatch system, a clinical decision tool, or a substitute for instructor-approved protocols.

Connect the classroom backend

Paste the Supabase project URL and anon/public key from your project settings. For a class deployment, put these in config.js as described in README instead of asking every student to enter them.

Don't use a service-role key in the browser. The supplied SQL is a simple classroom MVP policy and should be hardened before public production use.
